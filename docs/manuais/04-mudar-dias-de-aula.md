# 04 — Mudar os dias de aula de uma turma

**Objetivo:** a turma vai ter aula em outros dias (ex.: troca a terça pela segunda), sem bagunçar a presença que já foi lançada.
**Quem pode:** professor e assistente.

## Passo a passo
1. Menu → **Turmas** → toque na turma.
2. Em **Quadro de aulas**, toque nos dias para deixar o novo jeito (sem aula, regular ou reposição).
3. Em **O quadro novo vale a partir de**, escolha a data em que a mudança começa (normalmente hoje ou a próxima semana).
4. Toque em **Salvar**.

## O que acontece com o que já foi lançado
Nada se perde. O sistema guarda os dois quadros:
- **antes da data:** valem os dias antigos (o relatório de outubro continua com terça);
- **a partir da data:** valem os dias novos (o lançamento passa a mostrar segunda).

## Dúvidas comuns
- **Escolhi uma data errada.** Salve de novo com a data certa. Só não dá para escolher uma data anterior ao quadro atual.
- **A mudança é só por uma semana (ex.: feriado).** Não mude o quadro: simplesmente não lance presença no feriado (dia sem presença não vira aula nem falta) e, se houver aula extra, use a reposição avulsa ([manual 09](09-aula-de-reposicao.md)).
