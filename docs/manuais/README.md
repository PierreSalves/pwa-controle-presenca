# Manuais de uso — Controle de Presença

Tutoriais curtos para quem usa o sistema no dia a dia, organizados pelo **que você quer fazer**. Cada manual diz o que precisa antes, o passo a passo e as dúvidas comuns.

Endereço do sistema: **https://controlepresenca.tghservices.com.br** (abre no celular ou no computador; dá para instalar como app).
